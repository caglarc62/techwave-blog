  • Popülerlik ve Gelecek Güvencesi: Dünya genelinde en çok kullanılan yazılım dillerinden biri olması, öğrencilerin gelecekteki kariyerlerine doğrudan katkı sağlar.

Yarışmada Sorulan Problem Türleri ve Örnek Bir Python Kodu

Kahta Fen Lisesindeki yarışmada öğrencilerin algorithmic thinking (algoritmik düşünme) kabiliyetleri ölçüldü. Sorular genellikle döngüler (loops), koşullu ifadeler (if-else) ve fonksiyonlar (functions) üzerine kurgulandı.

Öğrencilere yöneltilen örnek problemlerden biri, verilen bir sayı dizisindeki asal sayıları tespit eden ve bunları küçükten büyüğe sıralayan bir algoritma yazmaktı. Aşağıda bu problemin çözümüne yönelik basit ve anlaşılır bir Python kod örneğini inceleyebilirsiniz:

def asal_mi(sayi):
    """Bir sayının asal olup olmadığını kontrol eden fonksiyon."""
    if sayi < 2:
        return False
    for i in range(2, int(sayi ** 0.5) + 1):
        if sayi % i == 0:
            return False
    return True

# Öğrencinin işlemesi gereken örnek liste
sayi_listesi = [17, 24, 3, 85, 11, 9, 2, 45, 29]
asal_sayilar = []

# Liste elemanlarını kontrol etme döngüsü
for sayi in sayi_listesi:
    if asal_mi(sayi):
        asal_sayilar.append(sayi)

# Sonuçları sıralama ve ekrana yazırma
asal_sayilar.sort()
print(f"Listedeki Asal Sayılar: {asal_sayilar}")

Yukarıdaki kod bloğunda görüldüğü gibi, asal_mi fonksiyonu bir sayının asal olup olmadığını matematiksel olarak kontrol eder. Ardından bir for döngüsü yardımıyla liste taranır ve şartı sağlayan elemanlar yeni bir listeye eklenerek sıralanır. Bu tür temel algoritmalar, yazılım eğitiminin yapı taşlarını oluşturur.

Genç Yazılımcılar İçin Altın Değerinde İpuçları

Bu tür yarışmalara katılmak isteyen veya yazılım dünyasına yeni adım atan lise öğrencileri için hazırladığımız pratik tavsiyeler şunlardır:

  1. Temel Kavramları Derinlemesine Öğrenin: Değişkenler, veri tipleri ve döngüler gibi temel konuları ezberlemeden, mantığını kavrayarak öğrenin.
  2. Bol Bol Pratik Yapın: HackerRank, LeetCode veya Codewars gibi platformlarda günlük kodlama egzersizleri çözün.
  3. Hata Mesajlarından Korkmayın: Yazılım sürecinin %50'si hataları çözmekten (debugging) geçer. Hata mesajlarını okumayı ve analiz etmeyi alışkanlık haline getirin.
  4. Kendi Projelerinizi Geliştirin: Sadece ders videoları izlemek yeterli değildir. Basit bir hesap makinesi, kelime tahmin oyunu veya rehber uygulaması yazarak kendinizi geliştirin.
